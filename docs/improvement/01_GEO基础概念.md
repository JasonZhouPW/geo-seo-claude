## 1.1 什么是 GEO？

**GEO（Generative Engine Optimization，生成式引擎优化）** 是一种新兴的数字营销策略，旨在优化内容和数字资产，使其在 AI 驱动的生成式搜索引擎中获得可见度、被引用和推荐。

### 核心目标平台

| 平台 | 类型 |
|------|------|
| **ChatGPT** | 通用对话式 AI |
| **Google AI Overviews** | 搜索引擎内置 AI 摘要 |
| **Perplexity** | AI 原生搜索引擎 |
| **Microsoft Copilot** | 生产力 AI 助手 |
| **Gemini (Google)** | 多模态 AI |
| **Claude** | AI 助手 |

---

## 1.2 GEO vs SEO：核心区别

| 维度 | 传统 SEO | GEO |
|------|----------|-----|
| **目标** | 搜索引擎排名页 #1 | AI 回答中的引用/推荐 |
| **核心指标** | 排名、点击率(CTR)、自然流量 | 引用频率、AI Share of Voice |
| **优化对象** | 关键词密度、反向链接 | 实体关系、语义结构、引用优化 |
| **内容需求** | 长篇权威内容 | 答案优先结构、统计支撑、可引用格式 |
| **效果评估** | Google Search Console | AI 平台手动测试 + 专用监控工具 |
| **生效机制** | PageRank 算法 | LLM RAG 检索 + 引用选择 |
| **用户路径** | 搜索 → 点击 → 浏览 | 提问 → AI 回答 → （可能无点击） |

### 关键认知转变

> **SEO 优化的是排名。GEO 优化的是被引用为答案。**

两者不是竞争关系，而是**叠加层**：

```
传统 SEO 基础（速度 + 可爬取性 + 权威性）
        ↓
   GEO 叠加层（实体 + 语义 + 引用优化）
        ↓
   最终效果：传统搜索 + AI 搜索双重可见度
```

## 1.3 什么是"AI 引用"？

当用户在 ChatGPT、Perplexity 等平台提问时，AI 会在生成回答时引用网页内容作为来源。这些引用通常以两种形式出现：

1. **内联引用** — 回答正文中直接提及品牌/数据，如"根据 [Brand] 的研究..."
2. **来源列表** — 回答末尾的"来源"列表，通常标注网页标题和 URL

```
示例：
提问："最好的项目管理软件有哪些？"

AI 回答：
"根据多项评测，以下是 2026 年最推荐的项目管理软件：

1. Asana — 适合团队协作（来源：[评测页面A]）
2. Monday.com — 适合远程团队（来源：[对比页面B]）
..."

这里的"[评测页面A]"就是一个 AI 引用。
```

**被引用的价值**：品牌在 AI 回答中出现，等同于获得了传统搜索 #1 位的曝光量级——且用户信任度更高。

## 1.4 为什么 2026 是转折点

**市场信号：**

- ChatGPT 每周 800 亿次访问
- Perplexity 每月 780 亿次查询
- Google AI Overviews 覆盖 60% 的搜索
- Gartner 预测传统搜索量将下降 25%

**零点击搜索加剧：**

| 数据 | 说明 |
|------|------|
| 58.5% | 美国 Google 搜索无点击 |
| 75% | 移动端无点击比例 |
| -61% | AI Overviews 出现时，CTR 进一步下降 |

**结论**：如果你的内容无法进入 AI 回答层，品牌在新一代搜索环境中将彻底隐形。

## 1.5 GEO 的三大核心要素

```
         ┌─────────────────┐
         │   可引用内容    │
         │  (Citable Content)│
         └────────┬────────┘
                  │  实体正确性
                  ▼
         ┌─────────────────┐
         │   实体权威性    │
         │(Entity Authority)│
         └────────┬────────┘
                  │  结构化格式
                  ▼
         ┌─────────────────┐
         │  语义可解析性    │
         │(Semantic Parsing)│
         └─────────────────┘
```

1. **可引用内容** — 包含统计数据、权威引语、清晰答案的内容
2. **实体权威性** — 品牌/人在知识图谱中的地位和关联强度
3. **语义可解析性** — AI 能否准确理解和提取内容要点
